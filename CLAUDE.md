\# Coin AI Project Rules



\## Rule 1 - Verification First



Never claim a feature works.



Only use:



\- Verified Working

\- Not Verified



Never use:



\- Should work

\- Probably works

\- Looks correct

\- Appears implemented



\---



\## Rule 2 - Browser Verification Required



Any dashboard change requires verification using Playwright.



Required evidence:



\- Screenshot

\- Observed behavior

\- Reproduction steps



Code review alone is insufficient.



\---



\## Rule 3 - Paper Trading Verification



Before claiming paper trading works, verify:



\- Balance visible

\- Positions visible

\- Trade history visible

\- PnL visible

\- Trade execution visible



If any are missing:



Report issue.



Do not mark complete.



\---



\## Rule 4 - Council Verification



Before claiming council automation works:



Verify:



\- New qualifying coin appears

\- Council automatically starts

\- Council finishes

\- Result attached to coin



Capture evidence.



\---



\## Rule 5 - No Hallucinated Completion



A feature is complete only if:



1\. Implemented

2\. Tested

3\. Observed

4\. Evidence collected



Missing any step = incomplete.



\---



\## Rule 6 - Audit Before Coding



Before implementing improvements:



1\. Observe system

2\. Gather evidence

3\. Identify root cause

4\. Propose fix

5\. Verify fix



Never jump directly to coding.



\---



\## Rule 7 - Profitability Goal



The goal is not:



\- More agents

\- More councils

\- More models



The goal is:



\- Better observations

\- Better evidence

\- Better calibration

\- Better outcomes



Always investigate whether a proposed feature improves expected profitability.

# AI Meme-Coin Sniper (Solana / pump.fun)

Real-time new-token sniper with built-in scam / honeypot / rug-pull checks, risk scoring,
buy/avoid recommendations, and a smart-money copy-wallet tracker. Node.js / TypeScript. Free APIs only.

> Status: scaffolding. Implementation plan is being refined via Ultraplan.

⚠️ **Risk note:** Meme coins are extremely high-risk and most go to zero. This is a personal
decision-support tool, not financial advice and not a guarantee of profit. Auto-buy is off by
default and dry-run even when enabled. Never commit your private keys — `.env` is gitignored.
